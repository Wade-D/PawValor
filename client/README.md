# PawValor 客户端：成长战斗试玩

使用 **Cocos Creator 3.8.6** 打开此目录。Git根目录在上一级，当前分支 `codex/phase-3-growth-core`；第三阶段前三步已实现，未合并到master。

## 安装与检查

```powershell
npm.cmd ci
npm.cmd run verify
npx.cmd tsc --noEmit -p tsconfig.json --ignoreDeprecations 6.0 --skipLibCheck --lib ES2020,DOM
```

`verify` 包含核心类型、依赖边界及Node测试，产物写入忽略的 `.test-build/`。2026-10-19最终 **364项测试通过**，额外适配器类型检查通过。核心不依赖Cocos、微信、DOM或Node API。

## 默认预览

1. 等待Creator导入，打开 `assets/scenes/CombatDemo.scene`，运行当前场景浏览器预览。
2. 默认“成长试玩”从空构筑开始，点击“开始”。WASD / 方向键移动，R重开；暂停、继续、重开按钮保留。
3. 蓝圆为雷恩，红圆为敌人，金色为普通剑气，青色为组合剑气，绿色为经验球。靠近拾取累计5经验，打开二级中文三选一。
4. 每局两次普通刷新；三级主路线三选一、七级分支二选一不能刷新；十一级自动记录终极，十二级仍有普通选择。
5. “构筑详情”显示天赋、路线、两个附魔位、两个副机制位及组合状态。选择期间模拟和伤害表现冻结，背景“继续”不能跳过选择；手动暂停与成长等待独立。

原型每段升级需要5经验，共55经验到十二级封顶，未经平衡测试。HUD显示已提交等级；跨级经验仍逐项选择。通用、附魔、副机制三类池均开启，候选不足三张时补入独立基础攻击、生命或移速+1%奖励。固有元素不占附魔位。

完整路线、分支和终极招式属于第四阶段，卡面已标注；雷霆路线固有雷属性已实际生效。

## 雷霆剑雨快速验收

预览地址追加 `?growthFixture=sword-rain`，右栏出现“准备组合前置 / 经验+5 / 经验+55”。该入口明示敌人生命200、移速0、接触伤害0，使用seed44和三个固定初始目标。

“准备组合前置”新建一局，经正常经验、抽卡、一次刷新和选择获得五级、万剑流、攻击强化二级、雷电附魔一级，不直接修改构筑。点击“经验+5”后，六级面板提示本级免费激活，仍保留三张普通卡。选择“额外弹体”可观察主弹、60%额外弹体与四枚组合剑气；D=24时组合各12伤害，不暴击或触发附魔、副机制及新组合。

组合夹角-18/-6/+6/+18度，只继承伤害、尺寸、射程的两层白名单交集。满足前置当级只排队，下一级选择提交后生效，不消耗选择、槽位或刷新。十二级新满足时只能待十三级，并显示本局封顶。

“经验+55”用于逐项处理至十二级，选择仍需真实点击。QA工具允许在模态期间追加经验或重建测试局，仅在显式测试地址出现；不能把QA敌人、经验与耗时当作自然玩法证据。

## 五个诊断入口

| 预设 | 直接注入的测试构筑 |
|---|---|
| 基础 | 第二阶段规则，敌人生命30、移速2，无成长构筑 |
| 通用强化 | 攻击/攻速/暴击率二级，其余非范围通用天赋一级，含额外弹体 |
| 火冰雷 | 固有雷与火焰/寒冰附魔各一级 |
| 雷电共鸣 | 固有雷与雷电附魔一级，使用共鸣追加伤害 |
| 副机制 | 追踪剑气、命中爆裂、范围增幅各一级 |

后四项敌人生命200、移速1。这五项仍使用旧战斗经验并二级封顶；完整选择请切回“成长试玩”。诊断HUD仍有一处“第三步接入”的历史提示，已记录待整理。`?combatFixture=secondary` 只为这五项提供三个固定目标。

模式切换和重开清除输入、固定步、旧弹体、状态、经验、选择、组合和动态界面。设计分辨率1280×720，64像素/世界单位，固定步1/60秒，每帧最多补5步。所有图形均为占位表现。

## 核心接口及边界

`GrowthCombatRun` 独占 `DemoWorld` 与 `GrowthSession`，暴露start/pause/resume/reset、step、select、reroll、grantXp、retryGrowth及只读snapshot。拾取统一交给成长流程，不重复走旧二级经验。构筑在同步事务内先校验、再原子应用；失败保存经验或原动作，显示中文错误，可重试或重开。旧弹体、灼烧、生命比例和冷却保留既有快照规则。

`GrowthSession` 仍可用于独立规则验证。令牌含会话、代次和版本；旧卡、旧局及跨实例选择被拒绝。外部随机源已消费的调用不因异常回滚。自定义commit钩子须同步且原子，不能依赖会话回滚其外部副作用。

`Bootstrap.scene` 保持第一阶段配置诊断用途。新增meta由Creator生成；43个资源UUID唯一、全部脚本有meta，场景对象引用、脚本类型和CombatDemo绑定静态检查通过，实际场景加载通过。MCP许可过期，专用场景验证器本轮未重跑。
