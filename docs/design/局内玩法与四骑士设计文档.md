# 《萌爪骑士团》局内玩法与四骑士设计文档

版本：2.0（开发基线）  
更新日期：2026年11月12日  
文档类型：局内系统与角色玩法设计  
适用范围：战斗操作、单局成长、关卡遭遇、四位骑士及其路线、战斗反馈与验证要求。

## 1. 设计范围与状态

本游戏为竖屏、单角色、移动中自动攻击的轻度动作肉鸽。局内体验围绕走位生存、随机选择和构筑成型展开。玩家直接控制角色移动，通过站位、移动时机和成长选择改变战斗结果。

本文所列角色方案全部采用。本文与《四骑士战斗参数与结算规格》《美术与局内界面制作规格》《局内开发阶段与验收计划》共同构成V1开发基线，替代此前阶段性设计记录。本文负责玩法与系统规则，战斗规格负责攻击数值与结算细节，美术规格负责资源与界面，阶段计划负责交付顺序。所有初始数值必须按配置实现，实测后允许调参；规则已经确定，不表示功能已经实现或平衡已经验证。

四位骑士均完整开发并纳入内测，开发入口默认全部可选；公开首发继续使用剑士、弓箭手、法师，巴顿以配置开关控制公开可用性，不以发布开关删减其开发内容。角色显示名统一使用“剑士”“弓箭手”“法师”“巴顿”。剑士为戴粉色蝴蝶结的金渐层幼猫，法师为无毛猫，巴顿为柴犬，弓箭手为长耳兔。前三位公开初始可用，不增加局外解锁任务。

V1不增加局外数值养成、经济或商业化系统；保存章节解锁、设置与本地关卡恢复快照。关卡结算不发局外货币。账号、云存档与运营发布另立范围，不作为局内开发阻塞项。

> 2026-11-14 起另有局外系统提案（训练天赋、共用装备、金币、体力、巡逻、成就），见[局外系统设计总稿](局外系统设计总稿.md)。该提案尚未批准；正式采纳前，本段“V1 不含局外养成与经济”仍然有效，采纳时须同步修改本段，并按总稿第11节核对[战斗规格](四骑士战斗参数与结算规格.md)的属性来源与上限。

## 2. 核心体验与单局结构

### 2.1 体验目标

1. **移动产生战术价值。** 玩家通过躲避、聚怪、维持照射、创造蓄力窗口和调整回程路径提高生存与输出。
2. **同一角色形成不同打法。** 主路线决定攻击核心，互斥分支明确取舍，终极强化该分支最重要的规则。
3. **随机选择形成局内变化。** 路线、主武器强化、通用祝福和共享机制竞争有限的选择机会。
4. **攻击结果能够预测。** 表现范围与实际命中一致；衍生攻击、重复命中、墙体遮挡和控制效果有明确边界。

### 2.2 单局目标与流程

| 项目 | 设计要求 |
|---|---|
| 操控单位 | 单名骑士，武器类型与角色绑定 |
| 基本输入 | 移动；局内攻击自动执行，现有角色方案不增加主动技能按钮 |
| 单局时长 | 正常通关目标为8—10分钟，包含升级选卡与NPC选择时间 |
| 等级范围 | 从1级开始，最高15级，最多十四次升级选择；不保证每局满级 |
| 额外选择 | NPC奖励独立计算，不消耗普通升级选择，不提升角色等级 |
| 单局边界 | 每关独立构筑；结束后重置等级、路线、技能与祝福 |

基本流程为：进入关卡并建立基础战斗循环，获取经验与成长选择，逐步形成路线或共享机制构筑，在波次或房间推进中处理NPC机会，完成关卡战斗后结束本局。Boss生命归零且玩家存活为胜利；同帧玩家死亡优先判负。主动退出记为中止，不保留本局收益。

8—10分钟是通关体验目标，不是三类关卡共用的强制倒计时。

## 3. 局内成长系统

### 3.1 路线结构

每位骑士具有三条互斥主路线。选择主路线后，本局锁定该路线；路线下设两个互斥分支，终极与所选分支对应。

普通升级采用随机三选一。主路线卡可在普通升级中出现；玩家可以暂不选择主路线，优先发展共享机制，也可以整局不选主路线。

分支与终极满足前置后进入随机候选，并设置出现保底。路线长期未出现时同样提供出现保底。保底保证选择机会，不自动授予能力，不强制玩家接受。高品质卡不能跳过合法前置。

路线、分支、终极不绑定固定等级节点。各路线统一使用入门、两次路线强化、分支、终极的五次选择下限，随机与保底执行第14章规则。

### 3.2 统一卡池与投入取舍

主武器强化、通用基础祝福、精灵、旋转球与植物进入统一升级池。取得某机制后，适当提高相关强化出现机会，同时保留其他构筑方向。

精灵、旋转球、植物可在同一局全部拥有，也可通过集中投入成为主要输出。获得共享机制不会关闭或牺牲主武器。三个首发角色使用同一种共享机制时，其基础表现与行为相同。

共享机制按第15章配置，三类各一个持有槽，互不排斥。V1不开放独立元素附魔卡、双附魔槽或自动共鸣配方；保留路线自带的冰霜、圣印、灼烧等效果。旧原型附魔与免费组合不进入正式卡池。

### 3.3 通用基础祝福

| 祝福 | 通用方向与适配边界 |
|---|---|
| 额外攻击次数 | 每轮增加一次完整攻击；多个来源相加，与连射为同一机制 |
| 两个斜向弹道 | 增加左右斜向攻击；与额外攻击组合时，每次均发出完整一组 |
| 贯穿 | 允许弹体继续命中沿途目标；天生贯穿的武器须转换为有效收益 |
| 弹射 | 命中后转向合法敌人，按次数消耗 |
| 分裂 | 从符合条件的主攻击生成二级弹体，不递归分裂 |
| 追踪 | 有限转向速度修正飞行方向，不赋予穿墙能力 |

弓箭手的额外连射箭和斜向箭不因这两种身份降低伤害。每轮直接发射箭数等于射击次数乘以每组箭数。后续连射沿用本轮原方向及斜向角度，不重新瞄准。剑士的额外攻击体现为额外挥砍剑气。法师与巴顿的具体适配见角色章节，不能将弓箭手规则无条件套用至全部专属攻击。

卡片品质只表达成长阶段，不随机改变同一卡的数值。经验、刷新与兜底按第14章执行。

## 4. 关卡与NPC遭遇

### 4.1 关卡组织

三类关卡编排在同一章节体系中，逐关解锁，不设置三个独立模式入口。

| 关卡类型 | 战斗组织 | NPC呈现 |
|---|---|---|
| 生存关卡 | 连续战场，迎战波次、精英与Boss | 波次间隙 |
| 顺序房间关卡 | 按预定顺序逐房推进 | 指定房间或节点 |
| 随机房间关卡 | 使用预制房间随机组路，分岔奖励类型可辨 | 通过路径选择获得或放弃遭遇 |

随机房间随机的是组合、连接和遭遇，不生成随机内部地形。关序固定为生存、顺序房间、随机房间，统一使用荒园城堡主题，具体配置执行第16章。

### 4.2 NPC选择

遭遇次数按关卡配置。NPC类型由配置指定，再从对应独立奖励池生成选项。触发后直接打开一次选择面板，不增加走近交互或对话流程。

| 类型 | 选择内容 |
|---|---|
| 祝福型 | 三选一，包含独立祝福或强化已获得技能 |
| 风险祝福型 | 三份契约选一份，明确展示临时惩罚、完成条件与兑现奖励 |
| 恢复型 | 固定二选一：立即恢复部分生命，或获得最低级属性祝福 |

所有NPC均可跳过，跳过消耗本次机会，不承担代价，不能重新打开抽取。NPC选项不能刷新。随机房间中可通过其他分岔放弃对应机会。三类关卡均可提供三类NPC功能。

### 4.3 风险契约

接受后立即承担临时惩罚。房间关按完成战斗房数、生存关按完成波次数推进契约；完成后自动解除惩罚，并授予事先展示的奖励，奖励持续至本局结束。

剩余关卡进度不足以完成的契约不进入候选。契约基本模型不采用单纯倒计时或击杀任务。同时最多一个契约，使用第17章规定的进度与结算规则。

## 5. 战斗公共规则

### 5.1 攻击身份与触发资格

弓箭手直接发射的本体箭、连射箭和斜向箭均为主子弹；分裂产生的箭为二级子弹。贯穿、弹射或更换底层实体对象不会改变逻辑箭矢身份，也不会清空命中记录。

二级分裂箭可造成直接伤害、独立暴击，并继承通用贯穿、弹射与追踪；不能再次分裂，也不能触发箭风、裂伤贯穿、流血、血痕引爆、疾猎叠层、爆破效果、狙杀增伤或处决。

其他角色的专属飞剑、射线、陨星、飞盾与共享攻击按各自规则定义，不能仅凭“额外产生的攻击”就统一视为主子弹或赋予全部路线触发资格。

### 5.2 箭矢分裂、贯穿、弹射与追踪

| 项目 | 规则 |
|---|---|
| 分裂时机 | 每支主箭首次命中敌人时触发一次，后续命中不恢复资格 |
| 分裂形态 | 从命中目标中心生成三支二级箭，相邻方向120°；一支沿命中前飞行方向，另两支为正负120° |
| 触发目标排除 | 分裂箭全存续期不能伤害、弹射选择或追踪选择生成它的那个敌人 |
| 次数继承 | 每支分裂箭获得来源主箭完整配置的通用贯穿与弹射次数，分别独立消耗，不继承裂伤专属贯穿 |
| 重复命中 | 同一支箭全存续期对同一敌人最多一次直接命中；不同箭分别计算 |
| 命中后运动 | 有次数且找到合法目标时优先弹射，只扣弹射；否则尝试贯穿，只扣贯穿；均不能执行则消失 |
| 弹射选敌 | 命中点限定半径内，全方向选择最近合法敌人，排除墙后与已命中目标；无目标不扣次数 |
| 追踪起步 | 先按初始方向发射，再有限速度平滑修正，不把斜向与分裂箭瞬间聚向目标 |
| 追踪寻敌 | 当前方向前方扇形内，优先夹角最小者，夹角相同选更近者 |
| 追踪保持 | 目标合法时持续锁定；死亡、超范围、已命中或被墙遮挡时重新寻敌；仅移出寻敌扇形不单独解除锁定 |
| 弹射与追踪 | 弹射立即转向新目标并将其作为追踪目标，后续继续平滑修正 |
| 无追踪目标 | 沿当前方向继续飞行，保留后续寻敌能力，仍受墙体、射程和寿命限制 |

分裂在无其他敌人的单体Boss战中不额外伤害该Boss。弹射的全方向选敌不受追踪前方扇形限制。追踪不执行绕墙寻路。

### 5.3 暴击与伤害属性读取

箭矢在各自发射或生成时独立判定是否暴击。同一逻辑箭矢贯穿、弹射后保留该判定，不因再次命中重新判定。不存在连续未暴击后的保底暴击。

实际伤害在有效碰撞时读取当前攻击方伤害属性、暴击倍率与目标防御。提前固定的只有是否暴击，不固定发射时的最终伤害。

爆炸和冲击波在各自生成时独立判定一次暴击，同一实例对所有目标共用该结果。它们不继承前序攻击的暴击结果，伤害基数也不重复带入前序暴击倍率；各目标受伤时再读取当时属性与防御。

分裂箭基于来源箭的非暴击直接伤害构成计算，保留适用折扣，重箭来源保留重箭倍率，再乘分裂系数并结算自身暴击。不得计入母箭暴击倍率、狙杀生命比例增伤、爆炸、冲击波或灼烧；不得直接复制母箭对先前目标造成的最终伤害。

灼烧、流血等BUFF持续伤害不暴击，每次跳伤读取当时属性与防御。施加攻击的暴击结果不传递至持续伤害。具体伤害公式、抗性、圣属性与元素附魔关系待统一。

### 5.4 命中、墙体与控制

基础横劈剑气较宽、射程较短，实际扫过的敌人均可受伤，不按命中人数消失；同一道剑气对同一敌人只结算一次伤害及对应圣印、裂甲或击退。明确规定的回程与地裂按独立段落处理。

攻击遵守各自射程、寿命和实体墙体限制。大型敌人不能因占据多个视觉段或接触时间更长而重复受击。爆炸按爆心至目标的实体墙体遮挡判断；冲击波与火区不能穿墙或绕墙传播。普通敌人与装饰物不作为上述实体墙体。

普通怪、精英和Boss均可被击退，Boss抵御较高、位移较小。连续击退衰减；击退只改变位置，不打断攻击或施法。位移后的敌方预警必须与实际命中一致。击退抵御与减速抗性分别设计。

## 6. 剑士

### 6.1 基础定位

剑士使用横劈剑气进行移动中自动攻击，依靠短中距离的路径覆盖作战。三条路线分别强调飞剑阵形、圣印审判与狭长贯穿。

| 主路线 | 分支一 | 分支二 | 核心走位价值 |
|---|---|---|---|
| 万剑 | 散华 | 聚锋 | 调整剑阵覆盖与终极回程路径 |
| 圣剑 | 惩戒 | 守誓 | 维持命中，积累审判，选择清场或生存 |
| 破军 | 裂甲 | 震退 | 将敌人引入狭长剑芒与地裂区域 |

### 6.2 万剑

每完成一次主武器基础攻击凝聚一柄飞剑，不要求命中；同次攻击的额外弹体不额外凝剑。共享机制与飞剑回程不参与凝剑。无合法目标不空挥积剑。蓄满后自动释放，基础剑气继续攻击，允许多轮剑阵并存。

入门每轮选择同一目标，飞剑发射时瞄准该目标位置，之后直线飞行、不追踪，命中一个敌人后消失，不自带贯穿。

| 阶段 | 散华 | 聚锋 |
|---|---|---|
| 分支 | 按固定扇形发射并获得贯穿，不逐枚分配敌人 | 形成沿攻击方向纵向排列的狭长矩形剑阵并获得贯穿 |
| 终极：万剑归宗 | 达到极限距离后停顿0.5秒，再返回角色 | 去程在共同远端点汇聚，先到者等待，到齐后合为高伤巨剑返回 |

聚锋汇聚点由本轮齐射起始时的位置与方向确定，不随角色移动。两种回程均追随角色当前位置，接触角色后消失；等待与停顿不造成伤害。

散华每柄剑对同一敌人去程、回程各最多一次伤害；聚锋小剑去程分别计算，合成巨剑对每个敌人最多一次伤害。回程绕弯不刷新命中资格。

飞剑、巨剑与缺剑汇聚按战斗规格实施，所有回程设定存续上限，不允许等待已销毁飞剑而永久阻塞。

### 6.3 圣剑

主剑气变为金色圣光剑气，获得路线提供的圣属性伤害加成。主剑气施加圣印，三层触发审判。

| 阶段 | 惩戒 | 守誓 |
|---|---|---|
| 分支 | 审判产生范围爆发，强化清场 | 审判获得有限护盾，提高持续作战能力 |
| 终极：周期性圣剑降临 | 强化金色剑气，以巨剑范围裁决增强清场 | 强化金色剑气并提供有限护盾 |

终极累计一定次数审判后自动进入短暂强化状态。圣属性不天然无视防御，也不默认对特定敌人翻倍。圣印、强化持续及护盾数值按战斗规格实施；降临期间不积累下一轮降临进度。

### 6.4 破军

横劈改为沿自动瞄准方向发射的纵劈窄剑芒，保持原攻速，提高单次伤害与射程，贯穿实际路径上的敌人。

| 阶段 | 裂甲 | 震退 |
|---|---|---|
| 分支 | 留下限时裂甲，提高目标后续受到的主武器伤害，有叠加上限，不依赖实际护甲值 | 沿剑芒飞行方向击退，遵守抵御与连续衰减，不打断攻击 |
| 终极：地裂 | 剑芒留下地裂，短暂延迟后造成一次较高的第二段伤害 | 留下较长时间地裂，持续减速并造成较低周期伤害，不追加击退 |

震退地裂重叠时，同一敌人只承受一份周期伤害，减速取最高值、不相加；各地裂独立计时。地裂采用战斗规格中的固定初值与触发资格，使用独立伤害实例。

## 7. 弓箭手

### 7.1 基础定位

基础攻击为较远射程、较快飞行的单发直线箭。发射时自动瞄准，基础不追踪，命中一敌后消失，可通过通用祝福获得贯穿。

| 主路线 | 分支一及终极 | 分支二及终极 |
|---|---|---|
| 暴击专精 | 裂伤重箭 → 血痕引爆 | 疾猎 → 疾风破阵 |
| 爆破箭术 | 震爆 → 震荡回响 | 余烬 → 燎原火海 |
| 蓄力狙击 | 狙杀 → 死线狙杀 | 游猎 → 满弦疾射 |

### 7.2 暴击专精

专属增益强化弓箭，不提高精灵、旋转球或植物的攻击能力。入门暴击率与暴击倍率按战斗规格叠加。

**裂伤重箭。** 暴击主箭获得裂伤专属贯穿并施加可叠层流血，箭身与碰撞宽度保持普通标准。每支实际暴击命中的主箭分别叠层，不受整轮一层限制。

流血新增层数时统一刷新全部流血的持续时间，但不重置跳伤节奏。首次施加等待一个完整跳伤间隔；未获得终极时，满层后的暴击命中维持上限并刷新时间。

终极“血痕引爆”在目标已满层后，由下一支暴击主箭命中触发。补满层的箭不同时引爆；引爆消耗全部流血，按引爆当刻属性结算未造成的剩余流血伤害，并追加一份单体伤害。触发箭不重新叠层，不先刷新流血。引爆不暴击、不连锁、不造成范围爆炸；第一跳前满足条件也可引爆，同一批流血只能消耗一次。

**疾猎。** 主箭实际暴击命中增加疾猎层数，提高主武器攻速与角色移速；同一轮所有主箭合计最多增加一层。层数有上限，触发刷新持续时间，超时逐层衰减，换目标不清空。

暴击主箭从射出时产生随箭移动的三角箭风，不要求疾猎满层。箭风尖端与箭头对齐，两翼向后展开，造成较低伤害与击退；同一道箭风对每个敌人最多一次伤害和击退，主箭消失时箭风消失。

主箭与箭风同时命中时，先结算主箭，再结算箭风，最后处理消失。仅被两翼扫中的敌人不算主箭命中，不增加疾猎层数。箭风不暴击，以主箭非暴击伤害为基础计算，击退沿对应主箭本次命中前的飞行方向。

疾猎终极直接提高箭风伤害、范围与击退，不增加满层条件或另一套计数。

### 7.3 爆破箭术

每支主箭仅在首次接触敌人时，于命中位置产生一次小范围爆炸。直接目标承受箭伤与爆炸伤害，周围目标仅承受爆炸伤害。后续贯穿、弹射不再次爆炸；连射与斜向主箭各自拥有一次资格。

爆炸独立判定暴击，不触发新爆炸、分裂或弹射。不同爆炸可分别伤害同一敌人。适用的来源伤害折扣沿派生链只计一次，不逐层重复相乘；连射与斜向身份本身不产生折扣。

**震爆。** 扩大爆炸范围，并将敌人从爆心向外击退。终极“震荡回响”在原爆炸位置延迟生成向外扩散的冲击波，不跟随箭矢或敌人；每圈对每个目标最多一次伤害，不追加击退，不递归生成效果。冲击波独立判定暴击，按实际命中时属性计算伤害。

**余烬。** 首次爆炸留下固定中心的短暂火区。进入火区施加灼烧与减速，不另外叠加一份火区直接跳伤。离开或火区消失后，该火区减速立即解除，灼烧保留剩余时长。

多个余烬来源的灼烧与减速分别取最高，不相加；两者可以来自不同火区。每片火区只维持自己的状态，弱火区不能为强灼烧续时。灼烧每次跳伤按当前属性比较有效来源，只结算最强一份。

同一敌人的余烬灼烧共用跳伤节奏：首次施加等待完整间隔，刷新、换区或最强来源切换均不重置、不额外跳伤；全部结束后再次施加才重新计时。已施加灼烧不会因目标后来移至墙后而清除。

终极“燎原火海”使火区逐渐扩大至上限，持续结束后熄灭。各火区独立计时，重叠不刷新彼此寿命，继续采用上述灼烧与减速规则，不增加新计数。

### 7.4 蓄力狙击

移动时普通射击；停步且有合法目标时开始蓄力，蓄力期间暂停普通箭。蓄满后自动发射高伤重箭，持续站立则循环蓄力。发射时重新瞄准，不锁定蓄力起点时的目标位置。

基础路线与狙杀分支在移动时取消蓄力；完全无合法目标时清空进度并暂停蓄力。有其他合法目标时可继续蓄力，发射时改瞄新目标。游猎将上述清空改为暂停并保留进度。

已开始的连射必须先沿本轮方向射完，之后才能蓄力，不并行积累。一次蓄满产生的整轮连射与斜向箭均为重箭；发射后允许移动打完整轮，目标消失也不取消已开始的连射。

普通射击冷却在蓄力期间继续计时，停走不重置冷却。每轮首箭发射时重新计算普通攻击冷却，同轮连射不反复重置；该冷却不阻挡停步蓄力或蓄满释放。攻速缩短普通射击间隔及蓄力时间；额外攻击次数增加完整箭组，不直接缩短蓄力。

**狙杀。** 目标剩余生命比例越高，主重箭伤害加成越高，不是按目标生命直接扣除固定百分比。贯穿与弹射对各目标分别判定。终极“死线狙杀”在重箭命中后，对剩余生命不高于处决线的目标直接处决；Boss采用独立阈值，箭伤折扣不降低处决线。分裂箭与共享机制不能处决。当前Boss按单阶段设计；若以后增加阶段血条，处决仅清空当前阶段并正常转阶段。

**游猎。** 移动与无目标时保留蓄力，停步且有目标后继续。普通状态下射出重箭后清零，移动不自行积累。

终极“满弦疾射”在蓄满时立即进入限时释放阶段并射出首轮重箭，随后按普通攻击间隔连续发射重箭，可自由移动。蓄力条按时间消耗，攻速不改变持续时间。无目标时不开始新一轮，但倒计时继续；已开始连射照常完成。到期不再开启重箭轮次，正在执行的一轮仍全部以重箭收尾。释放及收尾期间均不积累下一轮蓄力，收尾后从零准备。

## 8. 法师

### 8.1 基础定位与状态

法师初始使用自带小范围伤害的魔法弹，具有奥术射线、冰霜魔弹与陨星术三条主路线，全部纳入开发。

基础攻击：中等射程，发射时瞄准并直线飞行，初始不追踪；首次命中产生小范围魔力爆发，直接目标不重复叠算同源直击与溅射。获得贯穿或弹射后可继续运动，但每支主弹仅首次命中产生基础溅射。移动不打断攻击，无合法目标不空射。不增加蓝量或主动技能按钮。

### 8.2 奥术射线

射线替换魔法弹，循环为“持续发射—攻击冷却—再次发射”。冷却从照射结束后开始；攻速只缩短冷却，不缩短照射时间，也不默认提高内部跳伤频率。冷却期不补射魔法弹。

每轮起射自动瞄准，之后锁定方向。起点随角色移动，射线整体平移；下一轮重新瞄准。射线贯穿路径敌人，有最大射程，遇实体墙停止。敌人在范围内按固定间隔受伤，反复进出不重置伤害间隔。

| 阶段 | 聚焦 | 奥术烙印 |
|---|---|---|
| 分支 | 持续照射同一目标逐步增伤，有上限，脱离后重置 | 射线施加限时烙印，后续任意一轮命中可消耗并产生小范围爆炸 |
| 终极 | 巨能光柱：聚焦满额后，本轮射线变粗 | 烙印重生：引爆后自动补回烙印，下一轮可再引爆 |

本轮新挂烙印不能当轮引爆。普通分支引爆当轮不能重新挂印；终极允许自动补回，但每目标每轮最多一次引爆。爆炸不连锁引爆其他烙印，不同烙印爆炸可分别伤害同一敌人。

结算规则：聚焦按每道主射线、每目标独立累计，单次照射结束清零；满额只使对应射线变粗，不让其他目标自动获得满额增伤。多个脉冲与斜向射线共享本轮标识，不能互相视为下一轮；补回烙印获得完整有效期。

### 8.3 冰霜魔弹

保留魔法弹与首次溅射。主弹直接命中短暂冻结目标，首次溅射对其他敌人减速，不增加寒冷叠层或冻结槽。

| 阶段 | 冰封 | 碎冰 |
|---|---|---|
| 分支 | 延长冻结，主魔法弹对已冻结目标增伤 | 后续主弹命中已冻结目标，提前解冻并追加单体伤害 |
| 终极 | 凛冬冰封：首次溅射范围也可冻结 | 冰爆：碎冰追加伤害变为小范围爆炸 |

冰封增伤仅影响主弹直击与基础溅射。碎冰分支的基础溅射仍只减速，不因冰爆变成范围冻结。

普通怪与精英冻结时暂停行动，预警与攻击进度一起暂停、一起恢复，不清除攻击进度。重复命中不刷新冻结时间；解冻或碎冰后有短暂再冻结保护，伤害与减速仍有效。

Boss不停止行动，而获得满足分支条件的等时长冰封标记与受抗性约束的减速，不能借此跳过阶段。

碎冰按命中前状态判定：未冻结则正常伤害后冻结，已冻结则碎冰，不在同次事件重新冻结。冰爆不再次冻结、碎冰或生成子弹。二级分裂弹与共享机制不触发冰霜路线效果。主弹后续贯穿、弹射命中可冻结或碎冰，但不重复产生基础溅射。

### 8.4 陨星术

保留主魔法弹。每支主弹首次命中时，在命中位置显示预告并降下一颗陨星，延迟造成范围重击，不留下燃烧地面。首次命中即使击杀目标，陨星仍生成；后续贯穿、弹射、溅射与二级分裂弹不再召唤。

| 阶段 | 重陨 | 星雨 |
|---|---|---|
| 分支 | 中心区域伤害高于外围，预告显示内圈 | 一颗陨星转为固定区域内连续小陨星轰击 |
| 终极 | 天坠巨陨：范围扩大，全范围使用原中心伤害 | 追星雨：轰击区域缓慢跟随最初命中的目标 |

普通陨星落点固定，目标可移出。中心与外围只结算一份伤害。星雨按完整一阵设计总伤害，每颗只在实际落点伤害一次；不同主弹产生的星雨独立计时，可叠加伤害。

追星雨不换目标。原目标死亡、离开战斗空间或被实体墙隔开后，在最后合法位置完成剩余轰击。跟随只影响尚未预告的落点，已经显示的落点保持不动。

攻速增加主弹频率，不加速已有星雨或缩短落地延迟。弹体追踪不使普通陨星自动追踪。陨星不递归召唤，不触发分裂或弹射；伤害受当前战斗空间与实体墙遮挡限制。

### 8.5 通用祝福适配

| 祝福 | 魔法弹形态 | 射线形态 |
|---|---|---|
| 额外攻击 | 增加完整弹组 | 增加完整脉冲，全部脉冲结束后进入冷却 |
| 斜向 | 增加斜向主弹，分别拥有首次命中资格 | 增加同步斜向主射线，共用单次照射时间 |
| 贯穿 | 增加后续直接命中，不重置首次溅射与陨星 | 转换为有效射程收益 |
| 弹射 | 沿用弹射优先、贯穿兜底 | 从首次接触目标形成受次数预算限制的折射链，保留主束 |
| 分裂 | 首次命中生成仅造成直接伤害的二级弹 | 每道主射线首次命中生成一次二级弹，不因跳伤重复生成 |
| 追踪 | 平滑修正弹道 | 获得祝福后允许有限速度转向，升级基础锁方向规则 |

二级魔法弹不继承溅射或路线效果，沿用三枚120°分裂与触发目标排除。射线额外脉冲沿用本轮方向，各脉冲独立积累聚焦，不继承前次满额状态。

折射链须维持接触、距离与无遮挡，失效段停止伤害，本次不反复重建。同一逻辑射线各段对同一目标共享跳伤间隔，不重复累计聚焦或烙印。射线分裂伤害从主武器攻击力取独立系数，不复制整段照射累计伤害。

额外脉冲延长一轮占用时间，也会延后烙印下一轮引爆；其收益须结合攻击节奏验证。

## 9. 刀盾骑士巴顿

### 9.1 定位与基础

铁爪盾卫·巴顿采用柴犬骑士形象，右手短宽刀、左手厚重竖盾，低重心站姿。玩法围绕周期护盾与近中距离作战。三条方向为反甲盾、回旋盾、防御盾，三条路线均完整实施；路线投射的魔法飞盾使用独立圆盾轮廓，不改变手持竖盾。

基础攻击为短程刀气，三路线均保留，支持移动攻击。被动“整备护盾”在进入战斗时提供护盾，此后周期获得限时护盾。

护盾先于生命承受减伤后的伤害，溢出部分扣生命。不同来源独立计时，新护盾不刷新旧护盾，自然到期不算被击破。护盾按最早到期优先消耗，到期相同按创建顺序；容量不足时仅加入剩余容量，不挤掉已有层。

### 9.2 荆棘反击

护盾吸收敌人直接攻击时，向攻击者发射可被墙阻挡的盾刺。伤害由攻击力与实际吸收量共同决定，设置单次上限与全角色触发间隔。生命损失不提高反伤，自伤、地形和持续伤害跳数不触发。

| 阶段 | 尖棘 | 蓄震 |
|---|---|---|
| 分支 | 盾刺向目标附近溅射，直接目标不重复吃溅射 | 反击伤害改为储能，下次刀气命中释放 |
| 终极 | 荆棘王冠：每次周期护盾后首次有效反击，额外向周围释放一圈盾刺 | 王之返还：提高储能与释放上限，强化刀气扩大为震荡斩 |

储能有上限，不跨房间囤积，通过盾面亮度反馈，不增加资源条。路线节奏为有盾承接小攻击、反击输出、无盾撤离；主动掉血或站桩吃大招不应成为最优策略。

强化方向为周期盾量、盾刺攻击力系数、反击与储能收益上限。

### 9.3 往返猎杀

自动投掷魔法盾，保留实体盾与刀气。去程朝发射时目标位置直线贯穿，到射程或障碍后折返，回程追随角色当前位置。每面盾对每个目标去程、回程各最多命中一次。

| 阶段 | 重返 | 跳盾 |
|---|---|---|
| 分支 | 回程再次命中去程目标获得额外伤害 | 去程首次命中后，最多弹向另外两名敌人，再返回 |
| 终极 | 贯心回环：回程首次再次命中去程目标时，沿回程方向释放穿刺盾波 | 连环折返：倒序经过去程记录折点，再追随角色 |

盾波每目标一次，不生成新盾。折点记录位置，不持续追踪敌人；整个回程共享命中记录。回程被墙阻挡则消散，提前消散不返还冷却。最长存续时间按战斗规格限制。

玩家通过侧移改变回程，争取双段命中。强化方向为盾宽、飞行速度与投掷间隔。

### 9.4 环盾堡垒

两面魔法盾环绕攻击，每枚盾对同一目标设置独立命中间隔。有护盾时，环盾命中可限频补盾；当前盾量越高，环盾伤害越高，达到阈值获得完整增伤。

无盾时保留基础环盾伤害，但失去增伤与命中补盾，等待周期或外部护盾重新启动。循环不依赖击杀，单体Boss战也可运转。

| 阶段 | 铁壁 | 绞杀 |
|---|---|---|
| 分支 | 提高周期盾量，高于盾量阈值时获得有限减伤 | 有盾时提高环盾转速 |
| 终极 | 移动堡垒：周期护盾生效期间展开宽盾片，每轮有限次数拦截普通敌弹 | 钢铁风暴：周期护盾到来时消耗部分当前护盾，短时获得更宽、更强盾刃 |

移动堡垒不拦截光束、地面与大范围攻击。钢铁风暴不扣生命，不触发被敌击破收益。通用旋转球可共存，但不触发环盾专属补盾。

强化方向为单次补盾量、环盾伤害与宽度、周期盾持续时间；增加补盾量不取消全角色触发间隔。

### 9.5 成长与继承

额外攻击与斜向攻击强化刀气，不自动复制盾刺、飞盾或环盾。攻击力影响刀气与盾伤；攻速只加快刀气，不默认缩短盾牌机制间隔。护盾量与持续时间对三路有效。

共享机制不触发专属反击、回程效果或补盾。衍生攻击不递归生成同类效果，额外弹体不能绕过全角色触发限制。

四位角色统一按路线入门、两次路线强化、分支、终极共五次选择的下限成型；不绑定固定等级。

## 13. 操作、空间与运行状态

### 13.1 坐标与输入

逻辑画布720×1280，竖屏正交视角；1世界单位u等于32逻辑像素。标准战斗场地20u×26u，居中显示，单房间固定相机。角色受击圆半径0.35u，敌人半径见第16章；视觉外轮廓不直接作为碰撞体。

浮动摇杆在未被UI占用的屏幕区域按下出现，半径80逻辑像素，12像素死区；超过死区按位移比例给定速度，超出半径取满速。首根触摸控制移动，额外触摸仅响应UI；取消触摸或失焦立即清空移动。桌面调试支持WASD与方向键，斜向归一化，不支持手动攻击。

四角色基础移动速度均为5u/s，碰墙沿切线滑动，不穿过实体墙。玩家与敌人不作硬阻挡，敌人间轻量分离防止完全重叠。接触伤害受受击无敌控制，不按帧重复扣血。无翻滚、体力或主动技能按钮。

自动攻击选取武器射程内、无遮挡、距离最近的活敌，等距按实体ID排序；新一轮重新选敌，轮内方向规则按对应武器执行。停步判定为摇杆进入死区或键盘方向输入归零连续0.1秒。顶墙但持续输入不算停步；外力位移不取消已经满足的停步状态。进入选择面板不算停步蓄力时间。

### 13.2 状态与计时

运行状态为准备、战斗、选择、转场、暂停、胜利、失败、中止。只有战斗推进60Hz模拟时钟；最多每渲染帧补五步，剩余时长舍弃并统计。攻击、BUFF、契约、波次、满弦、护盾和动画事件均使用模拟时间，暂停不补算离线时间。

单帧先完成伤害、死亡与经验归属，再按“失败／胜利、升级选择、NPC、出口”的顺序处理中断。玩家与Boss同帧死亡判失败，已结束的局不再弹奖励选择。一次获得多级时排队逐个选择，全部完成后恢复战斗，不吞选择。

开始选卡时冻结世界、清空摇杆；关闭后等待新的触摸，不沿用旧按下状态。恢复战斗前有0.3秒可取消的视觉倒计时，期间仍冻结。普通升级必须选择，NPC与随机分岔可以按各自规则跳过。暂停页提供继续、音量、减弱特效、退出；退出需二次确认，避免误触丢局。

玩家受到敌方伤害后0.5秒受击无敌，护盾吸收也启动；无敌期间不发生伤害、吸收或反击。敌方持续伤害每次有效伤害也受此门控。护盾容量全角色统一为最大生命40%，补盾及吸收规则使用战斗规格。

### 13.3 转场、恢复与结束

保存点为进入新房间／生存新波次前、选择面板生成后、刷新提交后、任何选择提交后，以及切后台时的完整模拟步边界。每次保存同一时刻的完整纯逻辑快照：版本、种子与随机流、关卡／波次／生成队列、构筑、生命盾层、经验与掉落、候选与刷新余额、契约、玩家与敌人位置和AI、弹体与区域、命中记录、攻击轮次、状态与到期时间、待执行事件、计时器、递增ID与已兑现奖励ID。无需保存Cocos节点、音频或粒子，恢复时从逻辑对象重建表现。

恢复到该快照的确切模拟时刻并先进入暂停页，显示“已恢复至最近保存点”；不得保留保存点后的经验后再重置整房敌人，也不得将已消耗奖励重新发放。采用双槽快照、校验值与递增revision，完整写入成功后才切换有效槽。选择提交后的奖励、候选关闭与快照属于同一次事务；崩溃时恢复旧槽或新槽之一，不加载半次提交。恢复不得再次触发入场盾、房间初始化奖励或重抽当前候选。

切后台立即暂停；回前台停留暂停页。进程结束后只提供继续最近一局或放弃，V1不作服务器反作弊。配置版本不兼容时提示旧局无法恢复，可开始新局，不静默丢失或加载错误数据。

房间完成时收取场内剩余经验；清除飞行物、召唤敌人、区域、敌方状态、万剑积累、圣剑降临计数、疾猎、蓄力与盾牌储能。保留生命、等级、构筑、契约和刷新余额；清除全部护盾层，新战斗重置攻击冷却并触发巴顿入场整备盾，其他角色不免费获盾。精灵与旋转球重建，植物按新场规则部署。生存波次之间不执行房间清理，避免人工重置护盾与蓄力收益。

胜利记录关卡完成并解锁下一关，失败或中止不解锁；结束删除恢复快照。结算显示角色、关卡、结果、战斗时间、总用时、击杀、最终等级、路线与共享机制，并可重试或返回选关。伤害统计按直接武器、路线、三共享机制归类，派生伤害只记一次。

## 14. 成长配置与候选生成

### 14.1 卡定义与前置

卡池共120个定义：四角色各24个，通用弹道6个，通用属性6个，共享机制12个。多等级强化使用同一卡ID的rank，不算额外定义。仅当前角色的24个专属定义进入本局。

每角色24个定义由3张路线入门、9张路线强化、6张分支、6张终极组成。每条路线3种强化，各最多2级；累计选择该路线强化两次后，两个分支进入候选，同一强化升两级也满足。选定分支后，对应终极从下次升级开始合法。路线、分支与终极均只获得一次。

不选择路线时所有三张入门保持合法；选择后排除其他路线全部卡。一次选择只授予所选卡，不能顺带送分支、终极或进化。NPC只授予独立奖励，不计路线强化前置。

品质固定：通用属性与即时治疗为普通；弹道、路线入门及共享入门／强化为精良；路线强化与分支为史诗；终极与共享进化为传说。品质是卡框分类，不乘额外数值，也没有随等级升高自动变高品质的规则。

### 14.2 抽取算法与出现保底

候选按合法性过滤后，无放回抽三张不同ID。基础权重：属性10、弹道6、路线入门8、已选路线强化8、分支10、终极8、共享入门6、已持有共享强化6、共享进化6。已有路线的强化／分支／终极权重乘1.5；已持有共享的强化／进化权重乘1.5。只影响对应类别，不互乘多次。

每种关键阶段分别维护“合法但未在初次面板出现的已完成升级次数”。主路线自第一次升级合法，连续两次未出现后，下次面板锁定一张合法路线；分支与终极合法后，连续一次未出现，下次锁定对应候选。首次出现即清零，拒选仍视为已获得机会，之后重新累积。共享进化连续三次未出现后下次锁定。

保底槽最多一个，优先终极、分支、主路线、共享进化；同类按等待次数、ID顺序决定。保底路线在三条中按固定种子轮换，不永远只给同一条。其他两槽仍随机，路线选择从不强制。

每局两次普通升级刷新，所有普通升级共用。刷新不推进保底计数、不改变合法性；保底槽保持，其他槽重新抽取并尽量排除刚看到的卡，池不足时允许重现。计数只在提交升级选择时更新一次，不能用刷新刷出或消耗额外保底机会。升级15级仍执行同样规则，不自动成型。

合法卡不足三张时以即时治疗补足。即时治疗恢复最大生命20%，不增加等级或构筑，允许同面板出现多个，但每个显示同样结果；满血时显示“已满血，本次不恢复”。该兜底不计入120个永久卡定义。玩家不会被无效卡锁死面板。

### 14.3 经验与通用数值

从1级升到15级所需经验依次为：20、25、30、35、40、45、50、55、60、65、70、75、80、85，共735。经验不因升级丢失溢出，15级后停止累计。普通敌人掉落3经验，精英18，召唤单位与Boss不掉经验。经验球拾取半径1.5u，进入范围以10u/s吸附，无墙阻挡需求；距离小于0.2u结算。掉落合并必须守恒经验值，场上最多100个球，超限合并至最近球。

| 普通属性卡 | 每级收益 | 等级上限 |
|---|---|---|
| 锋锐 | 攻击力＋15% | 3 |
| 强健 | 最大生命＋15%，同时增加等量当前生命 | 3 |
| 迅击 | 攻速＋15% | 3 |
| 轻步 | 移速＋8% | 2 |
| 精准 | 暴击率＋8个百分点 | 2 |
| 致命 | 暴击倍率＋0.25 | 2 |

同类百分比加成相加后作用于基础值。生命卡增加的当前生命等于本次最大生命实际增量，例如强健一级增加150上限并恢复150，不按变化后的上限再乘15%。攻速总加成上限100%，移速总加成上限40%，暴击率最高80%；数值上限适用于卡、NPC、契约和路线的同属性合计。未达到上限的卡正常合法，某卡所有收益已封顶则过滤。暴击倍率最高3.0。

通用弹道上限：额外攻击＋2，每级＋1；斜向一档，左右各25°；贯穿两级每级＋1；弹射两级每级＋1；分裂一档、系数0.3；追踪一档、转向180°/s。其他距离、速度及不同武器适配采用战斗规格。没有固定高品质等级节点或免费跨流派组合。

## 15. 共享攻击机制

三种机制共享全局攻击力、暴击属性，不继承角色主路线专属增益，也不触发主武器附带效果。共有规则：独立冷却，无合法目标不攻击；攻击判定与数值读取使用战斗规格的直接伤害原则；不能触发通用连射、斜向、分裂、弹射、追踪或互相召唤。范围伤害受实体墙体遮挡。每种四个卡定义：入门、两种强化、一个进化；强化各两级，累计两次强化后进化合法，进化只取一次。

| 机制 | 入门 | 强化A（每级） | 强化B（每级） | 进化 |
|---|---|---|---|---|

A为命中时全局攻击力。旋转球每次合法接触独立判暴击；种子与精灵弹发射时判定，植物进化的爆裂共享该种子暴击结果，不另乘暴击。旋转球接触目标若球心至敌人被墙挡住则无伤害，无拦截敌弹能力。

植物不阻挡移动、不可被攻击；满数量时部署新株替换最早一株。新房开始立即部署第一株，其余按周期补齐；无敌人时部署计时停止，已有植物寿命继续。位置优先玩家后方0.8u，被墙挡时在玩家脚下合法点，始终限制当前房间。不存储跨房间弹体或植物。

所有共享强化只作用于自身机制。共享伤害单独统计，既不获得裂甲“主武器易伤”，也不替角色触发审判、蓄剑、裂伤、疾猎、烙印、冻结、陨星或盾牌循环。

## 16. 关卡、敌人与胜负配置

### 16.1 内容规模与节奏

一套荒园城堡主题，六个普通战斗房模板、一Boss房模板、一入口背景。普通房模板为开阔庭院、中央花坛、双侧石柱、左右通道、四角掩体、破损回廊；所有模板20u×26u，通道最窄2.5u。不可破坏墙与装饰分层标记，出生点距玩家至少6u且不在当前攻击预警范围，出现前0.8秒地面提示。

生存关共16波，波间起始间隔25秒；若到时上一波未清，等待清完再开始，不无限堆怪。每波敌数为8＋2×floor((波号－1)/2)。第4、8、12、16波各将一名普通敌替换成精英。第16波清场后进入Boss战；NPC选择时间不计波次间隔。正常波次最多400秒计划窗口，Boss目标60秒内，连同选卡与NPC形成8—10分钟目标，不设超时强制失败。

顺序房间共八个普通战斗房加Boss房；敌数依次16、20、24、28、32、36、40、44，第2、4、6、8房各替换一名精英。每房分四批，清完一批后2秒部署下一批，余数从第一批起均分；每房预计40—50秒。模板顺序按上述六种再接开阔庭院、破损回廊。

随机房间同样为八个战斗房加Boss房、相同总怪数与难度曲线。每次清房以两个带奖励图标的出口选项选择下一房；两项使用不同合法模板，不能连续重复当前模板。第2、4、6房之后提供一个NPC奖励出口与一个普通补给出口，其余分岔为不同地形同奖励。选择后加载下一预制房，不增加可步行分岔大厅。关卡随机种子决定模板、敌人和奖励，各自独立随机流，特效随机不得影响玩法。

### 16.3 Boss：苔甲守卫

生命18000、防御20、移动1.3u/s、半径1u，单阶段，不召小怪。依次循环扇形斩、圆形砸地、直线冲锋；每招结束后2秒恢复窗口，进入下一招前以1.3u/s接近至对应距离，接近最长3秒后以当前位置释放，不无限追人。

扇形斩：距离4u内，前方100°、半径4u，预警1秒，伤害220。砸地：以Boss当前点为中心半径3.5u，预警1.2秒，伤害260。冲锋：锁定方向，宽2u、长10u，预警1秒，以8u/s前进，触达墙或最大距离结束，路径伤害200；同一目标每次冲锋只伤害一次。所有预警固定，不追踪玩家后续位置。冲锋开始前若Boss被击退，预警路径作废并重新显示完整1秒预警，不能偷偷改变命中位置。

Boss减速抗性50%，击退抵御90%。冻结转冰封标记，不停招。所有敌人离开攻击路径后必须允许躲避，不能以无预警瞬移或全场必中特效补难度。

### 16.4 密度与生成限制

普通与精英合计最多50只，召唤物包括在内，Boss同时最多1只。达到上限时将计划生成排队，不能直接丢弃敌人或经验；正在召唤遇上限则本次不生成，保持召唤数量余额并等待下次周期。任何排队未完成都不算清场。

房间非战斗补给出口恢复最大生命10%，不提供升级卡或契约进度。所有战斗房不论选哪条分岔经验总量相同，避免选地形导致终极无法达到。预计可提供780经验（普通与精英替换合计），达到15级需要735；漏捡时仍可能不满级，清房自动收集降低这种损失。

## 17. NPC池与风险契约配置

生存第4、8、12波后依次恢复、祝福、风险；顺序房第2、4、6房后同序；随机关对应节点让玩家在该NPC与补给出口中二选一。该章节内NPC顺序固定，三种功能均出现，不随机NPC类型。跳过NPC后继续推进，不重新打开面板。

祝福NPC从独立六项池抽三项不同奖励：攻击＋10%、攻速＋10%、最大生命＋10%并补等量当前生命、暴击率＋5个百分点、随机一个已拥有共享机制伤害＋20%、已拥有主路线伤害＋10%。无共享时过滤共享项，无主路线时过滤路线项；已到全属性上限且无有效收益的项过滤。至少保留未封顶项，不足用恢复最大生命20%补齐。NPC路线伤害只作用于路线实例，不强化基础武器或共享；不计路线强化次数。

恢复NPC固定提供恢复最大生命35%，或随机一项最低级属性祝福（攻击＋5%、最大生命＋5%并补等量生命、攻速＋5%三者等概率）。两个选项之外提供跳过；数值固定不再随机品质。满血时恢复选项显示不可选，另一个仍可选。

风险NPC固定展示三份不同契约：

| 契约 | 立即代价 | 完成要求 | 完成奖励 |
|---|---|---|---|
| 迟缓誓约 | 移速－15% | 完成接下来2个战斗房或2波 | 攻击＋25% |
| 钝锋誓约 | 攻击－20% | 同上 | 攻速＋25% |
| 破甲誓约 | 受到伤害＋25% | 同上 | 最大生命＋25%，增加等量当前生命 |

负面与正面分别对同类属性加法累计，移速有基础速度50%的下限。伤害惩罚在防御减伤前乘1.25；不额外制造伤害事件。接受所在房／波不计数，从下一场清场计1；选择页、补给、Boss与返回旧房不计进度。存在未完成契约时风险NPC不提供第二份，仅显示当前进度与继续。

候选要求剩余至少两个可计数战斗单位，且完成后仍保留至少一场战斗（Boss可作奖励使用场，但不作契约进度）。完成进度立即解除惩罚、授予奖励后才处理升级与下一场。死亡、退出或结算时清除契约，不兑现奖励，不遗留局外惩罚。奖励持续本局且不占普通选择。

## 18. 工程边界、性能与交付

沿用Cocos Creator 3.8.6、TypeScript和纯core／引擎适配分层。纯核心负责规则、随机、战斗状态、碰撞与结算；Cocos层负责输入、节点池、动画、音效与UI。显示帧事件不能决定伤害时刻；动画按核心攻击事件播放。文档任务不直接修改当前游戏代码。

配置至少包含hero、route、card、attack、status、enemy、encounter、room、npc、artManifest及configVersion。每项使用稳定ID，中文显示名独立。攻击事件携带rootAttackId、logicalAttackId、roundId、segmentId、sourceKind、owner、target、spawnTime和hitLedger；对象池复用必须更换generation。技能资格以显式标记表判断，不依赖特效名或对象类名。

玩法、成长、关卡、奖励使用独立带种子随机流；UI与特效不能消耗玩法随机。每次模拟事件按时间、优先级、逻辑ID排序，伤害与消耗在同一事务中结算，避免多箭重复引爆。保留现有核心测试接口，迁移旧固定节点和快照规则后执行完整回归。

| 预算／指标 | V1验收目标 |
|---|---|
| 模拟 | 固定60Hz；丢时次数及秒数可观测 |
| 基准设备 | 目标60fps，实战帧时间P95≤20ms |
| 最低验收档 | 目标30fps，实战帧时间P95≤33.3ms，无持续超过100ms卡顿 |
| 内存 | 峰值256MiB以内，连续60分钟循环不持续增长 |
| 玩法实例 | 压测至少覆盖600个友方飞行体、120个敌弹、100个持续区域、50只敌人；这是测试负载，不是静默删伤害的上限 |
| 视觉降级 | 超过200个可见友方特效时合并非关键粒子、减少尾迹与数字；预警、主弹位置、伤害和命中资格保留 |
| 存档 | 每保存点提交同一局完整逻辑快照，写入失败保留上一有效槽并提示 |

至少在Android、iOS各一台真实微信设备记录型号、系统与微信版本进行验收。预算是本项目验收目标，不表示当前工程或平台已有该表现。若超预算，先优化查询、池化、特效与渲染，不私自少生成已获授权的攻击。确需改变攻击数量或收益时更新配置版本并重测对应构筑。

开发顺序为：迁移规格和坐标 → 基础战斗与灰盒敌人 → 剑士万剑散华完整成长垂直切片与一套正式美术 → 完整成长、共享机制与NPC → 剑士、弓箭手全路线 → 法师与巴顿全路线 → 三类关卡 → 全量美术音频、性能和真机验收。阶段任务、依赖与完成标准按开发阶段计划执行，不以“代码已写”替代可玩与可验收。
