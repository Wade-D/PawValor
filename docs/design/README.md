## 状态定义

| 状态 | 含义 |
|---|---|
| **基线** | 当前开发依据。规则已确定，数值为可调的初始配置，不代表已实现或已平衡 |
| **提案** | 设计方向已有用户要求，但机制与数值尚未批准，不能直接当作开发需求 |
| **附录** | 为某份基线或提案保留推导、依据或调研；规则以其主文档为准 |
| **历史** | 已被取代，仅供追溯，不再更新；与基线冲突时以基线为准 |
