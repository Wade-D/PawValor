# 《萌爪骑士团》四骑士战斗参数与结算规格

版本：V1开发基线｜日期：2026年11月12日

本文给出四位骑士的完整战斗配置、成长卡数值和结算边界，可直接转换为配置表与验收用例。全部数值为V1初始配置，允许依据试玩调节；规则已确定，数值尚不代表平衡验证结果。除明确允许的效果外，派生攻击不得产生新的主武器触发。各路线三种强化卡均为两级，每次选择升一级；标有“未分支时”的临时收益在选择分支后由对应正式收益替换，不并存、不要求重新抽取。已取强化按当前分支动态计算，仅属于另一互斥分支的效果不生效；卡面同时展示当前收益与分支后的变换，避免把临时增伤误认为永久叠加。

## 1. 基础单位、属性与计算

### 1.1 基础属性

1u等于32逻辑像素；设计画布720×1280。下表范围为战斗逻辑尺寸，不等同于角色贴图外框。

| 配置 | V1值 |
|---|---|
| 四位角色初始最大生命 | 1000 |
| 初始攻击力A | 100 |
| 初始防御 | 0 |
| 基础移动速度 | 5u/s |
| 角色受击圆半径 | 0.35u，位于脚底向上0.35u |
| 基础暴击率/倍率 | 5% / 1.5倍 |
| 暴击率上下限 | 0%—80%；暴击倍率上限3.0 |
| 攻速加成上下限 | -50%—100% |
| 移速加成上下限 | -50%—40%；减速再乘，最终速度不得低于基础速度50% |
| 玩家受击保护 | 承受一次敌方有效伤害后0.5秒；被护盾全吸收同样触发 |
| 敌方接触伤害 | 同一攻击者1秒一次，并受玩家受击保护限制 |
| 持续伤害 | 敌方持续伤害对玩家同样检查并触发受击保护，保护挡掉该跳不延期补伤；玩家施加的持续伤害对敌人按自身节奏执行 |

攻击力A＝100×(1＋所有攻击力百分比加成之和)；最大生命与移动加成采用相同加法组。最大生命增长时当前生命增加本次上限增量（强健一级为150），不按已增长的上限再计算比例；治疗和护盾明确按当前最大生命计算。普通攻击间隔＝基础间隔÷(1＋攻速加成)。冷却到期只在有合法目标、没有正在执行的攻击轮次时开启新轮次。

自动瞄准以角色为中心，在当前武器射程内选择最近且无遮挡的存活敌人；距离相同按敌人生成ID选择。选定方向在该轮锁定。攻击动作不锁移动，不因转身惩罚延迟伤害。无目标不开始攻击；正在执行的轮次按各职业规定收尾。

### 1.2 伤害公式

通用直接伤害＝A×技能系数×来源系数×(1＋同组伤害加成之和)×目标易伤倍率×暴击倍率×防御倍率×减伤倍率。

- 防御倍率＝100÷(100＋max(0,目标防御))。物理、奥术、圣、冰、火标签在V1共用此公式，无隐藏克制或无视防御。
- 暴击倍率在本次攻击判定暴击时读取当前值，否则为1。各攻击是否暴击的判定时点见继承表。
- 同一来源折扣只沿派生链继承一次。连射与斜向无身份伤害折扣，通用弹射、贯穿也不施加额外折扣；分裂系数单独计算。
- 范围、持续和路线专属加成各自为独立加法组；不同组相乘。不得把同一卡同时放进攻击力和伤害加成两组。
- 最终伤害内部保留浮点数，生命低于或等于0死亡；仅显示数字四舍五入，显示小于1的正伤害为1。
- 反击吸收量和蓄震储能使用专用公式，不再重复乘来源攻击力或前序暴击。

### 1.3 控制与护盾

| 参数 | 普通怪 | 精英 | Boss |
|---|---:|---:|---:|
| 击退抵御 | 0% | 50% | 90% |
| 减速抗性 | 0% | 25% | 50% |
| 冻结时长倍率 | 100% | 50% | 使用等时长冰封标记，不停行动 |

实际击退距离＝技能距离×(1－击退抵御)×连续衰减。目标1秒内第一、第二、第三次及以后击退倍率分别为1、0.5、0.25，连续1秒未受击退则重置。击退时间固定0.15秒，撞墙截断，不造成撞墙额外伤害。击退不中断施法，所有已产生的地面预警保持世界位置；Boss冲锋在启动前被击退时作废旧路径，按新位置重新给完整1秒预警，然后执行原定冲锋。

多个减速取最高，不相加；实际减速＝最高减速×(1－减速抗性)，最终上限70%。区域减速离区立即解除，限时减速按自身期限消失。

所有角色护盾总上限为当前最大生命40%。先计算防御与减伤，再由护盾吸收，溢出扣生命。最早到期层先消耗，同到期时间按生成ID；新增超容量部分丢弃，不延长旧层。自然到期、主动消耗与清场移除均不触发被击破事件。生命上限变化时护盾容量同步重算，超出容量按最晚到期层先裁剪。生命恢复不恢复护盾。

### 1.4 事件顺序

每帧使用固定模拟步长1/60秒；暂停不推进任何战斗时间。按发生时间、事件类别优先级、攻击ID、目标ID排序。同一时刻先执行已经到点的持续伤害，再移除已经到期的状态／护盾，再处理直接命中及其原子派生，最后处理死亡、经验与面板请求。直接命中读取不到已到期状态；新生成状态不补本时刻已结束的周期跳伤。死亡标记在扣至零时立即设置，仅奖励和流程切换等待收尾。

1. 检查目标存活、墙体、命中记录、受击保护和效果触发间隔；保留命中前冻结、流血层数与生命比例快照。
2. 计算并结算直接伤害；更新护盾和生命。
3. 执行该次合法命中的路线效果；狙杀增伤使用命中前生命比例，处决使用直接伤害后的生命比例；碎冰按命中前冻结状态决定。
4. 首次接触生成分裂、爆炸、基础溅射或陨星等有资格的效果；首次目标被直接击杀也不取消这些位置效果。死亡目标不再添加状态。
5. 处理同次箭风伤害和击退；再处理弹射、贯穿和实体消失。
6. 派生攻击按独立事件进入同帧队列。每个状态的消耗是原子操作，不能重复引爆同一批流血或烙印。

敌人生命归零即不再参与新目标选择。其死亡位置和首次命中快照保留到当前事件收尾。伤害与处决同帧重复命中只计一次死亡和经验。

普通弹体最大飞行路径长度为配置射程×(1＋通用贯穿次数＋通用弹射次数)，但寿命不超过3秒；剑气与刀气最大寿命2秒。所有飞行路径段累计计入长度，转向不重置寿命。射线另按照射时间控制。

宽剑气与刀气获得弹射后，在首次合法命中时按弹射规则转向，原形状跟随方向旋转；每次有效命中最多转向一次。没有合法弹射目标或次数耗尽后继续天生贯穿，命中记录不重置。先处理同帧扫到目标中的最近接触点，再转向，未到达目标不凭原宽度补伤。

分裂剑气、刀气与魔法弹统一产生半径0.16u的二级能量弹，速度14u/s、基础射程7u、寿命3秒。弓箭分裂保持箭形、速度18u/s、基础射程11u。二级弹仅伤害，继承完整通用贯穿和弹射配置及追踪；不能伤害生成它的目标，不继承来源专属状态。来源圣剑伤害类型、破军基础系数、重箭基础系数可保留，圣印、裂甲、击退、狙杀等命中效果不保留。

追踪不绕墙，无目标沿当前方向飞行。无追踪祝福时，连射、斜向、分裂保留原方向；具备追踪后先按原方向发射，再有限速度调整。斜向和连射每个直接攻击独立拥有首次分裂、爆炸等资格。

## 3. 剑士三路线

### 3.1 万剑

| 阶段 | V1配置 |
|---|---|
| 入门 | 每次完整挥砍凝聚1剑，4剑自动齐射；每剑0.65A、射程8u、速度12u/s、宽0.20u，无基础贯穿 |
| 散华 | 四剑在-24°、-8°、+8°、+24°方向发射，获得无限目标贯穿 |
| 聚锋 | 四剑沿攻击方向纵向排列，前后间距0.35u；共同方向发射，获得无限目标贯穿 |
| 散华终极：万剑归宗 | 达到最大射程停0.5秒，随后以14u/s回归；去程与回程各0.65A |
| 聚锋终极：万剑归宗 | 远端汇聚成巨剑，回程系数为每柄实际抵达小剑的0.90A之和，速度12u/s、宽1.2u |

额外攻击每次实际挥砍各凝聚1剑，斜向剑气不额外凝聚。齐射本身、分裂弹、飞剑回程不凝聚。凝聚达到4后立即扣除4并发射，后续仍可凝聚。入门四剑各自朝本轮选定目标位置瞄准；射出后不追踪。

每柄飞剑独立判定暴击；聚锋巨剑生成时独立判定暴击。飞剑不继承通用弹道祝福，受到攻击力与万剑专属强化影响。散华飞剑去回各保留一份命中记录；聚锋巨剑使用新记录，但不重新形成小剑。

聚锋共同汇聚点为齐射起点沿攻击方向8u处。墙阻挡的小剑在墙前消散并从待抵达计数中移除；当所有小剑抵达或被移除时，至少一剑抵达则立即合成，无剑抵达则结束。去程最久1秒，超时小剑视为丢失。散华去程撞墙消散，不在墙前额外停顿折返。所有回程遇墙消散，不绕墙。回程最久2秒，终止时不伤害；同场最多4轮剑阵，超上限的新齐射延迟到最早轮结束，凝剑数量封顶4而不丢失整轮已满剑阵；等待期间的额外凝剑不增加库存，这一并存限制写入万剑详情。等待剑阵在实际释放时读取当前配置、攻击方向与暴击率，不冻结等待开始时属性。

## 4. 弓箭手三路线

### 4.1 暴击专精

入门使弓箭主武器暴击率＋20个百分点、暴击倍率＋0.5。主箭、连射箭、斜向箭与分裂箭各自按发射时暴击率独立判定，无未暴击保底。贯穿弹射沿用原结果。以下专属触发只由主箭产生。

| 阶段 | V1配置 |
|---|---|
| 裂伤重箭 | 暴击主箭额外获得2次裂伤贯穿；流血最多4层，每层每0.5秒0.08A，持续3秒 |
| 血痕引爆 | 满4层后下一支暴击主箭引爆剩余流血，并追加1.20A单体伤害，不暴击 |
| 疾猎 | 最多4层，每层主武器攻速＋6%、移速＋3%；触发刷新4秒，超时每1秒减1层 |

环盾每次合法接触独立判定暴击，再读取当前盾量伤害；补盾在本次伤害后执行，不反过来提高这次伤害。无盾不能凭本次命中补盾重新启动；受到外部盾或下一次周期盾后可恢复。

环盾碰撞玩家至盾位置之间被墙遮挡的敌人时不造成伤害。移动堡垒以盾与弹体真实相交为拦截条件，不全屏拦弹；拦截消除弹体、不扣生命护盾、不触发反击。周期盾层用完或到期时关闭拦截，其他来源护盾不能续期。钢铁风暴主动消耗按最早到期层优先，不触发被击破；效果剩余时间不因后续破盾立即取消，但无盾仍失去普通盾量增伤和补盾。

### 7.2 房间、暂停与结束

切换房间时清理所有弹体、地面区域、陨星预告、攻击轮次、敌方状态、飞剑库存、疾猎层、蓄力与满弦、审判进度、储能和全部护盾。生命、路线、卡片与永久局内属性保留；下一战斗房开始按整备规则获得新盾，主武器就绪。安全房不触发空挥、凝剑或蓄力。

同一生存场地的波次切换不等于换房，不清空仍有效的状态或护盾；战斗暂停统一冻结计时。胜负结算时先锁定结果、禁新攻击，再清理全场效果，禁止遗留命中继续改变结果。

### 7.3 数值回归要求

每条路线按入门、分支、终极及“额外攻击2级＋斜向＋分裂＋弹射2级”组合验证。需要同时记录总伤害、单体Boss伤害、有效命中率、存活时间、同屏实体峰值和玩家能否解释伤害来源。达到对象预算前不允许通过无提示丢弃主攻击来维持帧率；超预算场景按开发验收规则处理，而不是暗中改变伤害。

规则测试至少覆盖：暴击固定而属性实时变化；分裂目标排除；满层流血同时命中；同轮多箭疾猎限层；多火区切换跳伤；满弦无目标到期收尾；多脉冲不提前引爆烙印；冻结暂停敌方预警；聚锋丢剑；飞盾墙边折返；护盾到期与敌击破区分；环盾无盾不能自启。
