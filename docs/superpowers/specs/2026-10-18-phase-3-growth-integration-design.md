## 1. 用户目标与范围

把独立成长核心接到实际战斗：玩家拾取经验后能看到中文三选一，选择后立即改变后续战斗；Lv.3/7固定选择和Lv.11自动记录按顺序发生。解除当前战斗入口的二级封顶，沿用已批准原型曲线：每级5点经验，累计55点到Lv.12封顶。十二级封顶是本轮测试参数，不代表最终等级或平衡结论。

第三步同时完成组合调度及一个可见组合“雷霆剑雨”。保留第二步五个诊断预设，新增默认“成长试玩”入口。默认入口从空构筑开始，不预先授予天赋、路线或组合，也不自动替玩家选卡。

三类普通天赋池均开启：通用、附魔、副机制。沿用现有合法性、槽位、能力前置、原权重及兜底规则；本步不另外引入品质、路线权重加成或“相关卡必出”。固定节点仍不消耗普通三选一。两次免费刷新按局共享。

完整路线、分支、终极攻击形态继续属于第四阶段。选择记录与名称正常呈现；万剑流、回旋剑流及各分支/终极尚未实现的招式，在卡面明确标注“招式效果在第四阶段实现”。雷霆路线已经实现的固有雷正常生效，不能把未执行的规划效果描述成已可用技能。

核心继续为纯TypeScript，不导入Cocos、DOM、Node或微信。玩家文案、新注释、Git提交日志使用中文；不自行合并或推送，保留三个本地未跟踪目录。

## 2. 接入方式及取舍

采用纯核心的战斗成长协调层，组合既有 `DemoWorld` 与 `GrowthSession`。Cocos只负责输入、命令、按钮和快照表现，不在组件中维护另一套经验、等级、组合前置或抽卡规则。

直接在Cocos中串接两套状态会使暂停、重复命令和跨级队列难以脱离引擎验证；把所有成长逻辑塞进DemoWorld则会扩大已有战斗职责及回归范围。新增小型协调层，使成长事务与战斗应用在同一同步边界提交，并保留旧Demo入口供回归。

| 模块职责 | 输入与输出 |
|---|---|
| 成长会话与组合调度 | 接收经验、令牌化选择/刷新，输出已提交构筑、当前选择、本级免费激活提示及一次性成长事件 |
| 战斗成长协调层 | 独占当前世界及成长会话；汇集拾取经验，管理成长等待/手动暂停，校验并应用构筑，发布组合快照 |
| 战斗执行器 | 原规则模式继续兼容；成长模式仅发布拾取数量，由成长会话统一拥有经验和等级；执行已编译组合弹体 |
| 中文成长面板 | 从快照生成普通卡、路线/分支卡、刷新、免费激活及终极提示，提交当前完整令牌 |
| 原型数据及验收入口 | 提供曲线、中文效果说明、雷霆剑雨执行参数与可复现测试数据，不反向被核心导入 |

成长模式不再调用二级封顶的 `applyDemoXp`。世界的旧等级字段不能被当作成长模式的等级来源，也不能把有上限的旧经验再次累加进GrowthSession。公开协调快照清楚区分战斗快照与成长快照；HUD只取成长会话的已提交等级和经验进度。

未开启成长模式时，原DemoWorld及五个效果预设仍保持第二步行为，包括诊断入口二级封顶的明示文案。默认“成长试玩”的文案改为“原型等级上限12级”。

## 3. 一步模拟与成长事务

正常运行时，先执行一个既有固定步；其移动、接触致死优先、直接命中、元素、副机制、状态与拾取顺序不改变。英雄若在接触阶段阵亡，本步后续伤害和拾取仍跳过。

协调层收集该固定步全部 `xpPickup` 数量，再统一向成长会话入账。由这次经验产生的全部升级目标进入现有队列。当前固定步已发生的攻击保留原构筑；升级效果从成功提交后的新发射/新施加开始生效，不回溯修改在途弹体与灼烧。

出现待选或待处理成长时立即停止后续固定步，清除移动输入及固定步累积。即使同一渲染帧尚有补步预算，也不继续模拟。暂停期间敌人、弹体、灼烧、效果显示时间和拾取全部冻结，不按真实时间补跳。

每个目标等级按以下顺序串行处理：

1. 在临时事务构筑中，处理历史pending且 `activateAtLevel` 等于目标等级的组合。按配置顺序移到active集合，幂等去重；本级不重新扫描并立即激活其他组合。
2. 用这份事务构筑生成当前节点选择：普通三选一、Lv.3三路线、Lv.7本路线两个分支；Lv.11自动终极记录。
3. 等待当前选择；刷新仍使用该事务构筑，不重复激活组合或重放事件。当前已提交构筑在确认前不变；界面可提示“本级免费激活”，但不让未提交事务提前影响战斗。
4. 提交当前节点后更新等级及构筑。检查本级新满足且不在pending/active的组合，记录 `eligibleAtLevel = 本级`、`activateAtLevel = 本级+1`。
5. 校验可执行构筑，再同步提交；返回一次性的组合/终极事件。之后才处理队列中的下个等级，直到再次等待选择或队列为空。

因此在Lv.6新满足的组合，在Lv.7事务开始处理，免费激活且仍保留Lv.7分支选择；在Lv.10新满足的组合，Lv.11自动事务同样激活；通过已激活组合满足的另一组合，只能排到再下一级。一次获得55点经验也不能跳过任何选择。

若Lv.12才新满足组合，仍记录待Lv.13激活，但本轮曲线无法到达13；HUD注明“本局已封顶，待激活”，不能在12级额外补发。

本级免费激活在临时构筑中先于候选计算，保证以active组合为前置的卡可在该级参与候选；直到本级提交成功，才更新公开已提交构筑和输出激活事件。不会出现“取消或非法选择已消耗免费激活”的半提交。

公开快照另外提供“本级将免费激活”的只读列表，供面板显示，不把临时构筑伪装成已提交构筑。新局初始化也扫描1级已经满足的组合前置，将其排到2级，不能在1级立即激活；当前雷霆剑雨不满足空构筑，所以默认不会产生该排队。

## 4. 暂停、命令与失败处理

协调层区分手动暂停、成长等待和阵亡。普通“继续”只能解除手动暂停，不能绕过未完成的成长选择。选择提交成功且队列已清空、没有手动暂停、英雄仍存活时自动继续；否则保持停止。

选择/刷新继续使用完整会话、局次与选择版本令牌。按钮携带渲染时的令牌；刷新、重开、切换入口或换卡后，旧按钮回调即使迟到也被拒绝。不能只提交卡片索引或把旧回调改绑为新令牌。连续点击只接受第一次有效命令；拒绝不扣次数、不应用属性、不重放提示。

成长更新在临时数据上完成，战斗构筑编译成功前不提交成长；协调层在待开始或暂停、当前世界代次匹配的同步边界应用同一份已校验构筑。校验失败不能发生“天赋已获得但战斗应用失败”，也不能恢复战斗或清掉当前选项。校验器收到隔离的只读数据，不得重入成长修改。

同一步已拾取但尚未成功入账的经验由协调层保留。若抽取或配置校验异常，停止模拟并提供中文“重试/重开”入口；重试成功后只入账一次，不要求回滚已经结束的战斗固定步。外部随机源已经消费的调用次数仍不承诺回滚，与第一步约定一致。常规玩家错误返回中文拒绝，开发诊断可保留详细错误到控制台。

最大生命变化沿用第二步生命比例规则；应用不重置攻击/元素/副机制冷却，也不改变旧弹体尺寸、穿透、伤害及旧灼烧快照。不得因选择、关闭面板或恢复运行使死亡英雄复活。

## 5. 雷霆剑雨的原型配置

用户已选定执行可见组合，沿用现有测试前置和四枚50%伤害参数，继续标注为测试配置，不宣称正式平衡。

| 项目 | 规则 |
|---|---|
| 玩家名称 | 雷霆剑雨；构筑详情显示“测试组合” |
| 前置 | 英雄雷恩，万剑流，雷电附魔至少1级，攻击强化至少2级；全部同时满足 |
| 获取 | 满足后的下一次升级免费激活，不占普通选卡或附魔/副机制槽，不消耗刷新 |
| 发射 | 每次实际主攻击发射时，保留主弹体及已有额外弹体，另发射一组四枚组合剑气；无合法目标时不发射或积攒补发 |
| 方向 | 相对本次主攻击方向等间隔扇形，原型总夹角36度，即-18/-6/+6/+18度；同一英雄发射位置 |
| 单枚伤害 | 本次英雄有效非暴击主攻击伤害D的50%；D=20时为10，攻击强化二级D=24时为12；不使用60%额外弹体的伤害作为D |
| 弹体 | 独立straight配置，速度12世界单位/秒、宽0.3/长0.8、寿命1秒、基础穿透0；有效射程沿用主武器及允许的射程修饰 |
| 继承 | 仅攻击伤害、弹体尺寸、射程，效果/弹体两层白名单取交集，各修饰只应用一次 |
| 禁止继承 | 暴击率/暴伤、穿透增幅、附魔、副机制、额外弹体、范围增幅；每枚首次碰撞后消失 |
| 来源 | 四枚attackId互不相同，继承本次主攻击rootAttackId，sourceKind为synergy、depth为1；不伪装direct、不再次触发组合 |
| 次数限制 | 本次根攻击最多发射一组，额外弹体不重复发射；独立组合策略允许direct、最大深度0、每根1次，原型额外冷却/目标间隔均0，组内命中由各弹体处理 |
| 快照 | 发射时保存已编译构筑、伤害和几何；之后升级或切换构筑不能追溯改变在途组合剑气 |
| 显示 | 与黄色主剑气、紫色追踪、橙色爆裂区分的青色剑气；伤害提示为“雷霆剑雨”；不额外追加一份雷元素伤害 |

四枚组合剑气可以分别命中同一存活敌人，每枚最多命中一次；不是整组只允许命中一个敌人。同敌人若已死亡，剩余剑气不能重复击杀或掉落。普通主攻击继续按其白名单结算雷附魔和其他效果，组合剑气本身不再触发。

执行行为由类型化配置字段和引用决定，不通过中文名或任意ID分支判定。组合执行描述与弹体运动、继承、触发策略必须一致；激活了本步不能执行的组合时明确拒绝，不能只显示名称而静默跳过。

现有组合示例ID可保留以兼容引用，但改为本步可执行测试组合，补入执行描述与独立弹体/策略。其他未激活的规划招式仍可保留在配置中。编译预检所有可达伤害、尺寸、角度和射程等计算结果，避免运行途中才发现Infinity/NaN。

## 6. 中文界面与默认入口

CombatDemo默认进入“成长试玩”。顶部或独立模式栏可切回第二步五个诊断预设，切换整局重建，不给已有世界叠加构筑。成长模式不显示“本入口暂为二级封顶”；诊断模式保留该提示。

HUD显示已提交等级、到下一级的经验进度、原型12级上限、生命、击杀、时间、刷新剩余次数，以及当前路线/分支、两个附魔位/两个副机制位和组合pending/active状态。经验可达等级与已提交等级不同期间，不把最终经验可达等级冒充已选择等级。

普通升级弹出三张不同卡，显示中文名称、类别、本次等级变化、具体效果及必要的槽位提示；独立基础奖励卡明确写“独立累计+1%”，不伪装成普通天赋。点击一张即提交；普通选择提供“刷新（剩余次数）”，用完后禁用。固定节点按三条路线/两个分支展示，不提供可点击刷新。

Lv.11自动终极记录显示一次中文提示，明确完整招式属于第四阶段；若紧接Lv.12选择，不丢失终极或组合提示，也不添加重复确认弹窗。免费组合提示不另占一张普通卡。构筑详情展示已选项目及等级，未满足组合可显示前置进度，不能展示代码ID。

选卡遮罩覆盖并拦截背景输入。进入选择清空键盘/摇杆意图，选卡按下/抬起不驱动摇杆；退出后必须重新按键或开始新的摇杆触摸。支持选择期间重开，旧命令立即失效。禁止以真实时间setTimeout推动升级、组合激活或伤害表现。

界面通过运行时节点构建，复用现有CombatDemo绑定，优先避免修改序列化场景。新增脚本元数据由Creator生成，禁止编造UUID；组件销毁清理监听、按钮、遮罩、伤害文字与状态节点。

## 7. 重开、模式切换与随机源

重开恢复空构筑、1级、0经验、两次刷新；清空选择/队列、待入账经验、pending/active组合、终极提示、手动暂停、输入、弹体、灼烧、冷却与动态界面。清理后才启动新局，旧句柄和旧令牌失效。模式切换同样重建并清理，不能把诊断预设携带到成长试玩。

战斗刷怪、直接暴击及成长抽取各用独立、确定性随机源。相同种子和相同操作可复现；刷新不改变刷怪序列。重开按同一新局种子规则创建或复位随机源，不能沿用上一局已消费的成长随机状态。

## 8. 测试与验收

1. 原338项行为约束保留，必要契约更新有明确原因；完整verify、核心依赖边界和兼容参数的适配器类型检查通过。新增公开只读快照可直接用于构筑编译和候选查询。
2. 组合调度覆盖普通/路线/分支/自动终极事务；满足当级不激活、下一等级免费激活、连续组合延后一等级、刷新不重复执行、pending/active幂等、Lv.12保留待激活、多级经验逐项处理及重开清空。
3. 协调层覆盖每步多经验球统一入账、5点经验触发实际选择、跨级队列、55点封顶但待选保留、升级冻结、手动暂停独立、继续不能绕过选择、生命比例、旧弹/旧灼烧、冷却保留、接触死亡无后续拾取。
4. 原子边界覆盖非法构筑不提交、校验重入拒绝、异常经验留待重试且不重复入账、旧选择/旧局/跨实例命令、重复点击、刷新失败不扣次及随机源隔离。
5. 雷霆剑雨覆盖正确前置及激活时间；每次主攻击恰好新增四枚、保留主/额外弹体、无目标不补发、夹角/独立ID/共享根/来源深度、D=20时10及D=24时12、继承交集、禁用暴击/附魔/副机制/穿透增幅、根限次、不同弹体可命中同一存活敌人、仅一次击杀/掉落、发射快照及溢出拒绝。
6. Creator实际导入、元数据UUID唯一、场景引用及浏览器控制台检查。实际中文预览复查普通选择、刷新、固定节点、自动提示、pending/active组合、属性生效、暂停/继续/重开及模式切换清理，保存关键截图。
7. 提供与默认玩法分开的可复现测试入口：通过真实经验入账及合法选择准备成长状态，不直接篡改等级或active组合；可固定种子、敌人位置及注入有限经验以覆盖Lv.2到12和雷霆剑雨。默认玩法不注入经验、不自动选择；测试参数在画面明确标记。若需快速组合验收，可先确定性执行合法前置选择，再等待下一等级验证免费激活。
8. 桌面按钮点击、触屏按钮、真实摇杆/多点触摸、微信设备分别报告。已有真机待验项继续保留；核心/桌面通过不构成设备或性能通过。安排一次独立全分支审查，重要发现复现后修复并重跑验证；不自行合并或推送。

## 9. 成本与明确限制

雷霆剑雨保留普通攻击并额外发四枚50%剑气：一组全部命中时，非暴击原始伤害最高额外增加2D，激活后直射实体量明显上升。它用于验证组合架构与可见差异，尚未经过平衡或微信设备性能验证。

每级5经验和12级上限复用规则原型，不保证自然游玩能在合理时长内体验完整进化；默认敌人/拾取规则不因验收而暗中修改。快速验收走显式测试入口，平衡调整另行确认。

完整万剑、回旋、连锁和终极招式仍未实现。卡面清楚说明记录与实际执行的区别，避免再次把配置选择当成可玩的招式。当前已确认槽位、伤害、状态及第二步快照规则全部沿用；不顺带扩展更多组合、英雄、存档、服务端或正式美术。
