# PawValor（萌爪骑士团）

微信小游戏，竖屏、单角色、移动中自动攻击的轻度动作肉鸽。使用 **Cocos Creator 3.8.6** 打开 `client/`，Git根目录为本目录。

| 目录 | 内容 |
|---|---|
| `client/` | Cocos 客户端工程；当前为第三阶段原型，见[客户端说明](client/README.md) |
| `docs/design/` | 设计文档，从[设计文档索引](docs/design/README.md)开始阅读 |
| `server/`、`config/` | 未来服务端与共享配置预留，目前为空 |

## 原型现状与基线差异

第三阶段成长核心原型已合并到 `master`。2026-10-19 记录 364 项测试通过，真实触屏、持续按键时序与微信真机尚未验证。

原型仍使用早期测试参数，**不代表正式规则**。迁移到 V1 基线的主要差异如下，完整清单见[开发计划](docs/design/局内开发阶段与验收计划.md)第2节：

| 项目 | 原型 | V1 基线 |
|---|---|---|
| 画布与尺度 | 1280×720 横屏，64逻辑像素/单位 | 720×1280 竖屏，32逻辑像素/单位 |
| 等级 | 每级5经验，12级封顶 | 15级，正式经验表 |
| 路线与终极 | 3/7级固定节点，11级自动终极 | 合法候选与出现保底，终极须经选择获得 |
| 构筑槽位 | 两附魔位、两副机制槽、原型免费组合 | 移除旧限制与旧配方，原型 fixture 仅作历史回归 |
| 角色 | 占位角色“雷恩” | 剑士、弓箭手、法师、巴顿四骑士 |

运行、预览与诊断入口见[客户端说明](client/README.md)。
